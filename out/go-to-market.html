OPEN MATRIX SDK

11.3 Open Matrix SDK Ecosystem

twin3 opens the Twin Matrix as a shared infrastructure layer through two complementary SDKs, enabling a thriving ecosystem of applications built on human identity data:

MATRIX (READ)

Read SDK

Third-party apps, dApps, and AI agents can read specific Twin Matrix dimensions (with user consent). Use cases: personalized recommendations, targeted matching, filtered access, reputation checks.

MATRIX (WRITE)

Write SDK

Ecosystem partners can issue specialized SBTs, write verification results, and contribute new credentials to user profiles. Use cases: skill badges, course completions, health records, community roles.

The Matrix SDK is the primary use case for the Ecosystem Growth pool (15% of total supply) — developer grants, hackathons, and integration bounties all drive adoption of the Read and Write SDKs across web, mobile, dApp, and agent ecosystems.
